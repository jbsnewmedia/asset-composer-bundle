## Release 1.1.2 – Changelog Summary

This release focuses on strengthening test coverage, improving development workflows with Docker and CI, and updating dependencies to Symfony 7.3 for long-term compatibility. It also introduces enhanced asset validation for safer and more reliable asset handling.

* **Expanded Test Coverage**
  Added new test cases for services, controllers, Twig extensions, and integration scenarios. Introduced `FixtureHelper` and additional edge-case coverage for more robust validation.

* **Improved Asset Validation**
  Strengthened security by preventing directory traversal, validating asset file existence, and restricting URL versioning logic to `.css` and `.js` files only.

* **Dockerized Development Setup**
  Added `Dockerfile`, `docker-compose.yml`, and a helper script for an easier and consistent local development environment.

* **CI Workflow Integration**
  Introduced GitHub Actions workflow for automated code quality checks, PHPUnit tests, and coverage reporting.

* **Refined PHPUnit Configuration**
  Split configuration into coverage and no-coverage variants, enabling more flexible and efficient test runs.

* **Composer & Dependency Updates**
  Updated Symfony components to v7.3 and added `symfony/yaml`. Refined `composer.json` scripts for streamlined CI and testing.

* **Bug Fix: Route Configuration Path**
  Corrected source path resolution in `AssetComposerExtension.php` to ensure proper loading of route configuration.

**Compatibility:** Backward compatible
