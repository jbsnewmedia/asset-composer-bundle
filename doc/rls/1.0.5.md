## Release 1.0.5 – Changelog Summary

This release focuses on improving asset handling, configuration clarity, and developer experience. It introduces cache-busting for assets, strengthens validation and security, and updates documentation and dependencies for better maintainability.

* **Symfony & PHP Rector Update**
  Rector config updated to target Symfony 6.0 and PHP 8.0, ensuring compatibility and modern coding standards.

* **Cache-Busting Support**
  Added `setUrlVersions` method to automatically append version identifiers to asset URLs, improving cache control and delivery of updated files.

* **Service Configuration Cleanup**
  Simplified `services.yaml` definitions, using autoconfiguration for Twig extensions while keeping explicit entries for documentation.

* **Controller & Extension Refactor**
  Improved dependency injection in the controller and readability in the Twig extension with stricter typing and docblocks.

* **Filesystem Integration**
  Replaced manual route file handling with Symfony’s Filesystem component for more reliable setup and error handling.

* **Enhanced Asset Validation**
  Strengthened directory traversal protection, clarified error messages, and improved runtime validation of asset paths.

* **Dependency Upgrades**
  Updated composer dependencies, including phpstan, rector, php-cs-fixer, react, and Symfony components, bringing new features and fixes.

* **Code Quality Improvements**
  Standardized formatting, enhanced type safety, and added runtime checks for more robust and maintainable code.

* **Documentation Overhaul**
  Revamped README with clearer structure, installation steps, examples, testing instructions, and improved project layout description.

**Compatibility:** Backward compatible
