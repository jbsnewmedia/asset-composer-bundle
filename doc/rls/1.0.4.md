## Release 1.0.4 – Changelog Summary

This release strengthens asset delivery security with version validation, improves routing and service definitions, and refactors code for better maintainability. Minor formatting and syntax issues were also addressed.

* **Asset Version Validation**
  Assets now include a version hash derived from file metadata and the application secret, preventing stale or tampered asset usage.

* **Expanded Content Type Support**
  Content type definitions were modularized and expanded, ensuring correct headers for a wide range of file formats.

* **Routing Improvements**
  Routes now enforce HTTP `GET` methods and stricter asset path requirements, improving clarity and security.

* **Service Configuration Update**
  Services receive environment and secret parameters, and the Twig extension is now properly registered, ensuring integration consistency.

* **Refined Error Messages**
  Exception messages were standardized for better readability and debugging clarity.

* **Code Cleanup and Formatting**
  Corrected indentation, syntax, and minor typos to align with coding standards without changing functionality.

**Compatibility**: Backward compatible
