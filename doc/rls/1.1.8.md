## Release 1.1.8 – Changelog Summary

This release adds support for Symfony 8 and improves the documentation around local assets, making the bundle ready for the latest Symfony LTS cycle while keeping everything backward compatible.

* **Symfony 8 Support**
  `symfony/framework-bundle` and `symfony/yaml` now allow `^8.0` in addition to `^6.4|^7.0`.
  *Benefit: the bundle can be used in Symfony 8 applications out of the box.*

* **Documentation: Local Assets in Twig Templates**
  The English and German READMEs now explain how to serve project-local files from `%kernel.project_dir%/assets/` using the `app/assets` namespace, including an example file structure.
  *Benefit: clearer onboarding for using your own assets alongside Composer packages.*

* **Development Environment Housekeeping**
  Docker document root adjusted to `/app`, `.gitignore` refreshed and reordered, and `public/.gitkeep` added to keep the directory in version control.
  *Benefit: smoother and more predictable local development setup.*

**Compatibility:** Backward compatible, no breaking changes. Symfony `^6.4|^7.0|^8.0` and PHP `>=8.1` are supported.
