## Release 1.1.0 – Changelog Summary

This release updates the bundle to align with Symfony 6.4/7.0 and PHP 8.1+, introduces `readonly` properties for improved immutability, and adds a `composer.lock` file to ensure consistent dependency management across environments.

* **Dependency Locking**
  Added a `composer.lock` file to guarantee predictable and reproducible builds across different environments.

* **Symfony 6.4 & PHP 8.1 Upgrade**
  Updated the codebase and Rector configuration to target Symfony 6.4 and PHP 8.1, ensuring compatibility with current frameworks and language features.

* **Readonly Properties**
  Refactored constructors to use `readonly` properties, improving code clarity and enforcing immutability where applicable.

* **Twig Extension Improvements**
  Updated Twig function definitions to use the `...` callable syntax, resulting in cleaner and more modern code.

* **Framework-Bundle Compatibility**
  Adjusted composer constraints to support Symfony 6.4 and Symfony 7.0 (instead of requiring Symfony 7.2+).

**Compatibility**: Breaking Change – Requires PHP ≥8.1 and Symfony ≥6.4.
