## Release 1.0.0 – Changelog Summary

Initial stable release of the Asset Composer Bundle.

This version introduces the core functionality for managing and generating asset files via Composer scripts within Symfony projects.

* **Automatic Asset Dumping**
  Automatically generates asset files during `composer install` and `composer update` using post-install and post-update hooks.

* **Configurable Output**
  Define output paths and asset content directly in your `composer.json` for flexible asset management.

* **Symfony Integration**
  Seamlessly integrates with Symfony while remaining usable in general PHP projects.

* **Extensible Architecture**
  Designed with extensibility in mind, allowing developers to adjust or override core behavior as needed.

This release establishes the foundation for future enhancements with a focus on simplicity, maintainability, and modern PHP standards.
