## Release 1.1.4 – Changelog Summary

This release focuses on dependency management improvements to ensure broader compatibility and cleaner versioning for users of the bundle.

* **Dependency Constraint Fix**
  Updated `symfony/yaml` requirement to use a proper caret (`^6.4|^7.0`), ensuring compatibility with patch and minor updates in both major versions.

* **Composer Cleanup**
  Removed `composer.lock` from version control to avoid locking dependencies in a library context, giving consumers more flexibility when installing.

**Compatibility:** Backward compatible
