## Release 1.0.1 – Changelog Summary

This release introduces `assetcomposer.json` support for enhanced asset protection and updates the configuration structure to align with Symfony 7 conventions. It also includes toolchain updates and documentation improvements for easier development setup.

* **Asset Protection with `assetcomposer.json`**
  Added support for defining allowed assets via `files` and `files-dev`, preventing unauthorized asset access in production and development environments.

* **Symfony 7 Path Adjustments**
  Configuration files were relocated from `Resources/config` to `config/`, ensuring compatibility with Symfony 7 best practices.

* **Controller Registration**
  `AssetComposerController` is now automatically registered in `services.yaml`, simplifying bundle integration.

* **Composer Metadata Update**
  Maintainer email updated in `composer.json` to reflect the current contact information.

* **New Developer Documentation**
  Added `README.dev.md` with setup tips for Composer memory limits and PhpStorm integration for PHPStan.

* **Static Analysis & Coding Standards**
  Updated dependencies for PHPStan, Rector, and ECS to their latest versions, improving code quality and tooling stability.

**Compatibility**: Backward compatible
