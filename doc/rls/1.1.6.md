## Release 1.1.6 – Changelog Summary

This release refines asset URL versioning, improves CI performance, and removes unnecessary lock files to ensure greater flexibility and more predictable asset handling. It also updates URL generation behavior and test expectations for more robust integration.

* **Enhanced URL Versioning Logic**
  Normalizes asset paths using `parse_url` and better handles `app/`-prefixed assets.
  Ensures more reliable and consistent version hashes across environments.

* **Improved Query-String Handling**
  Version parameters are now correctly appended even when URLs already contain query strings.
  Prevents malformed URLs and ensures predictable cache-busting.

* **Composer Lock Cleanup for Tooling**
  Removes multiple `composer.lock` files under `vendor-bin/`, avoiding locked tool dependencies.
  Gives users more flexibility and reduces CI friction.

* **CI Updated for PHP 8.3**
  The CI pipeline now tests against PHP 8.3.
  Ensures forward compatibility with the latest PHP versions.

* **Faster PHPUnit Execution**
  Switches CI to `bin-phpunit-no-coverage` by default.
  Reduces build times and speeds up development iteration.

* **Standardized Absolute URL Generation**
  Enforces `UrlGeneratorInterface::ABSOLUTE_URL` for asset routes.
  Guarantees consistent URL outputs across environments and routing contexts.

* **More Flexible Test Expectations**
  Relaxes strict URL generation constraints in `AssetComposerAdvancedTest`.
  Makes tests more stable when URL strategies evolve.

**Compatibility:** Backward compatible.
