## Release 1.0.2 – Changelog Summary

This release focuses on improving the documentation for easier setup and integration. The updated README clarifies configuration placement and introduces guidance for using `assetcomposer.json` in external libraries.

* **Updated File Structure Overview**
  The README now reflects the correct placement of configuration files under `config/`, making it clearer for Symfony users.

* **New Guidance for External Libraries**
  Added detailed instructions and a JSON example for using `assetcomposer.json` in other libraries or tools, ensuring smoother asset inclusion.

* **Improved Repository Links**
  Fixed and clarified GitHub repository references for issue reporting and contributions.

**Compatibility**: Backward compatible
