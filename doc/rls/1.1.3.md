## Release 1.1.3 – Changelog Summary

This release updates dependency constraints to improve compatibility with recent Symfony versions, ensuring smoother integration for projects on Symfony 6.4 and 7.x.

* **Symfony Yaml Compatibility**
  Updated the `symfony/yaml` requirement to allow both `6.4` and `^7.0`, expanding support across current and upcoming Symfony versions.

**Compatibility:** Backward compatible
