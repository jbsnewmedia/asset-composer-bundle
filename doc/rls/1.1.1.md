## Release 1.1.1 – Changelog Summary

This release introduces improved configuration options, better Symfony/PHP compatibility documentation, and a dedicated PHPUnit setup with initial test coverage. It strengthens project maintainability and testing practices.

* **New AI Configuration File**
  Added `ai.json` to define ignored extensions, folders, and filenames for asset composer, allowing more flexible customization.

* **Ignore Helper Files in Git**
  Updated `.gitignore` to exclude `ai.txt`, PHPUnit cache files, and the `/var/` directory for a cleaner repository.

* **Updated Requirements**
  README updated to reflect compatibility with PHP 8.1 and Symfony 6.4/7.0, ensuring clarity for users on supported environments.

* **Dedicated PHPUnit Setup**
  Added `phpunit.xml.dist` and a `vendor-bin/phpunit` configuration for structured and isolated test dependencies.

* **Composer Test Scripts**
  Introduced PHPUnit bin scripts (`bin-phpunit`, `bin-phpunit-v`, `bin-phpunit-install`, `bin-phpunit-update`) to simplify test execution.

* **Initial Unit Tests**
  Added test coverage for the Controller, Twig Extension, and Service classes to validate core functionality.

* **Route Configuration Refactor**
  Asset composer routes were moved into a dedicated configuration file for better project structure.

**Compatibility:** Backward compatible
