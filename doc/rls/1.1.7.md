## Release 1.1.7 – Changelog Summary

This release focuses on hardening asset delivery and versioning logic, alongside modernizing the toolchain and CI for a more reliable developer workflow. Users benefit from stricter path/security handling, more robust URL cache-busting, and clearer project documentation.

* **Hardened Asset Security & Validation**
  Strengthened traversal and file validation checks (e.g., realpath/symlink scenarios) with expanded test coverage.
  *Benefit: safer asset serving and fewer edge-case vulnerabilities.*

* **Improved URL Versioning in CSS/JS**
  Refactored URL rewriting to version referenced local assets more reliably, including query-string handling and root-dir resolution fallbacks.
  *Benefit: better cache-busting behavior without breaking external/data URLs.*

* **More Robust File Handling**
  Cast `filemtime()` results to integers, added early returns when versioning roots are missing, and silenced non-critical `file_get_contents()` warnings when vendor files are inaccessible.
  *Benefit: fewer runtime warnings and more predictable behavior in imperfect environments.*

* **Dependency & Runtime Alignment (PHP 8.1)**
  Docker and CI now target PHP 8.1, and PHPUnit is aligned to `^10.0` with schema `10.5` for compatibility.
  *Benefit: improved compatibility and consistent local/CI execution.*

* **Twig Now Required**
  Added `twig/twig` as a required dependency and aligned related tooling configs accordingly.
  *Benefit: ensures Twig integration works out-of-the-box.*

* **Modernized QA Tooling & Configs**
  Updated PHPStan/Rector dependencies and migrated Rector config to the fluent API; improved global PHPStan settings.
  *Benefit: smoother static analysis/refactoring with up-to-date tooling.*

* **Streamlined CI Workflow & Coverage Uploads**
  Renamed and simplified GitHub Actions workflow, runs coverage by default, and uploads to Codecov with stricter failure behavior.
  *Benefit: clearer CI signals and more consistent coverage reporting.*

* **Documentation & Developer Guides Added**
  Added development/project guides and introduced a German README while refreshing the main README commands and formatting.
  *Benefit: faster onboarding and fewer setup pitfalls.*

**Compatibility:** Backward compatible (runtime/tooling requirements aligned to PHP 8.1; Twig is now required).
